# Regras do projeto

- Este é um projeto Electron + JavaScript.
- Não criar portfólio.
- Não criar landing page.
- Não recriar a aplicação.
- Preservar a arquitetura existente.
- Não utilizar OBS.
- Não modificar funcionalidades sem necessidade.
- Antes de implementar uma funcionalidade, analisar o código existente.
- Priorizar alterações pequenas e compatíveis com a arquitetura atual.
- O alvo principal é Windows.
